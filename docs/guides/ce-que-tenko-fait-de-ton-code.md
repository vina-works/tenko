# Ce que Tenko fait de ton code

Ton code est ce que tu as de plus sensible. Voici précisément ce qu'il en advient.

## L'accès demandé

Tenko demande un accès **en lecture seule** à ton dépôt. Il n'a pas le droit d'y écrire :
ce n'est pas une promesse, c'est l'autorisation elle-même qui ne le permet pas. Aucune
modification, aucune suppression, aucune publication n'est possible depuis Tenko.

L'autorisation d'accès est chiffrée sur nos serveurs, et tu la retires en un clic depuis
tes réglages. À partir de cet instant, plus aucune analyse ne peut démarrer.

## Ce qui est copié, et pour combien de temps

Pour analyser ton code, Tenko en fait une copie temporaire, le temps de l'analyse. Cette
copie est supprimée à la fin. Chaque analyse est isolée : un projet ne voit jamais le code
d'un autre.

Ce qui est conservé, ce sont les résultats : les constats, leur emplacement, ta note, ton
historique. Pas ton code.

## Ce qui est envoyé à une intelligence artificielle

Deux choses seulement font appel à un modèle d'IA : la rédaction des explications en
français et celle des textes de correction. Trois règles s'appliquent :

- les passages repérés comme contenant un mot de passe ou une clé sont masqués **avant**
  l'envoi ;
- seuls les extraits nécessaires à la cause traitée sont envoyés, jamais le projet entier ;
- ton code n'est jamais utilisé pour entraîner un modèle. C'est écrit dans le contrat et
  imposé au fournisseur.

Le calcul de ta note ne passe par aucune intelligence artificielle.

## Où vivent tes données

Tes données et leur traitement restent dans l'Union européenne. Chaque action des
automatismes de Tenko est inscrite dans un journal que tu peux consulter et exporter. La
suppression complète d'un projet se demande depuis tes réglages et est effective sous
trente jours.

## Ce que Tenko ne fait pas

Tenko ne déploie rien, ne pousse rien, ne contacte pas tes utilisateurs et ne partage tes
résultats avec personne.
