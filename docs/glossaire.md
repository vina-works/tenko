# Glossaire

Les mots que tu croiseras dans Tenko, en une phrase chacun.

### Axe

Un des cinq angles sous lesquels ton code est noté : sécurité, dépendances, structure,
tests, dette. Voir [Les cinq axes](guides/les-cinq-axes.md).

### Branche

Une des versions parallèles du produit rangées dans un même dépôt. Celle que voient tes
utilisateurs s'appelle en général `main`.

### Cause

Un regroupement de signaux de même nature, par exemple « trois mots de passe écrits en
clair ». Tenko affiche toujours les trois causes qui pèsent le plus sur ta note.

### Contester

Signaler qu'un constat te paraît faux. Il cesse de peser sur ta note le temps qu'une
personne tranche. Voir [Contester un signal](guides/contester-un-signal.md).

### Crédit

L'unité qui compte les actions payantes pour Tenko (rédiger un prompt, une explication).
Ton palier en inclut un nombre chaque mois. Voir
[Ton budget et ton plafond](guides/budget-et-plafond.md).

### Dépendance

Une brique logicielle toute faite, entretenue par une autre équipe, que ton produit
utilise.

### Dépôt

L'endroit où ton code est stocké, sur GitHub.

### Note

Une lettre de F à A qui dit à quel point ton produit est solide aujourd'hui, pour une
version précise de ton code. Voir [Lire ta note](guides/lire-ta-note.md).

### Plafond

Le montant de dépense mensuel au-delà duquel Tenko s'arrête net, sauf si tu demandes plus.

### Preuve

Ce qui permet à Tenko de constater qu'une correction a bien eu lieu, en relisant ton code
après coup. Voir [Ce qu'est une preuve](guides/ce-qu-est-une-preuve.md).

### Prompt

Le texte d'instructions que Tenko rédige pour que ton outil d'IA (Claude Code, Cursor,
Lovable, Bolt) corrige une cause. Voir [Coller un prompt](guides/coller-un-prompt.md).

### Pousser

Enregistrer une modification sur ton dépôt. C'est ce qui déclenche la vérification par
Tenko.

### Signal

Un constat isolé relevé dans ton code : un mot de passe à tel endroit, un fichier trop
gros, une brique trop ancienne.
