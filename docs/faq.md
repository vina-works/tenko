# Questions fréquentes

### Faut-il savoir coder pour utiliser Tenko ?

Non. Tenko est fait pour les personnes qui ne lisent pas le code : la note, les causes et
les critères de réussite sont écrits en français courant. Voir
[Premiers pas](premiers-pas.md).

### Tenko peut-il modifier ou casser mon code ?

Non. L'accès demandé est en lecture seule : l'autorisation elle-même interdit toute
écriture. C'est toi qui colles le prompt dans ton outil et qui décides de pousser. Voir
[Ce que Tenko fait de ton code](guides/ce-que-tenko-fait-de-ton-code.md).

### Mon code sert-il à entraîner une IA ?

Non, jamais. C'est écrit dans le contrat et imposé au fournisseur. Seuls les extraits
nécessaires sont envoyés, mots de passe et clés masqués au préalable.

### Où sont stockées mes données ?

Dans l'Union européenne. Tenko conserve les résultats d'analyse, pas ton code : la copie
faite pour l'analyse est supprimée à la fin.

### Ma note a baissé alors que je n'ai rien touché. Pourquoi ?

Soit une faille vient d'être publiée sur une brique que tu utilises, soit les règles de
calcul ont changé de version (c'est alors marqué sur la courbe). Voir
[Lire ta note](guides/lire-ta-note.md#pourquoi-la-note-bouge).

### Par quoi commencer quand la note est mauvaise ?

Par la première des trois causes affichées : Tenko les classe déjà, sécurité et
dépendances d'abord. Voir [Les cinq axes](guides/les-cinq-axes.md).

### J'ai corrigé, mais la tâche n'est pas marquée prouvée.

As-tu poussé la modification ? Tenko ne vérifie qu'après. S'il l'a vue, il te donne le
motif en une phrase. Voir [Ce qu'est une preuve](guides/ce-qu-est-une-preuve.md).

### Un constat est faux. Je fais quoi ?

Tu le contestes en une ou deux phrases ; il cesse aussitôt de peser sur ta note. Voir
[Contester un signal](guides/contester-un-signal.md).

### Que se passe-t-il si j'atteins mon plafond ?

Tenko cesse de rédiger de nouveaux prompts, mais continue de calculer ta note. Rien n'est
dépensé sans ton accord. Voir [Ton budget et ton plafond](guides/budget-et-plafond.md).

### Mon outil n'est pas dans la liste.

Les prompts sont mis en forme pour Claude Code, Cursor, Lovable et Bolt. Si tu en utilises
un autre, [propose-le](https://github.com/vina-works/tenko/issues/new/choose).

### Ma question n'est pas ici.

Pose-la dans les [discussions](https://github.com/vina-works/tenko/discussions).
